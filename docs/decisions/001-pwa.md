# ADR 001 — PWA em vez de app nativo

## Status

Aceito (Product + Architecture)

## Contexto

Colaboradores precisam de experiência próxima de aplicativo no celular, incluindo tela cheia e push. Há pedido explícito para **não** usar React Native/Flutter.

## Decisão

Entregar **Progressive Web App** no mesmo monolito Next.js: manifest, service worker, `display: standalone`, ícones, instalação quando o browser oferecer.

## Consequências

- Um código, três form factors; store não entra no MVP.
- iOS exige “Adicionar à Tela de Início” e versão mínima para push — limitações visíveis ao usuário.
- Capacidade nativa (badge complexo, sync background amplo) fica fora.
